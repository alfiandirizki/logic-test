### **Deskripsi Soal**
Buatlah sebuah fungsi atau program yang menerima sebuah angka bulat `n`. Cetak (*print*) angka dari `1` sampai `n` ke layar secara berurutan dengan aturan sebagai berikut:
- Jika angka habis dibagi **3**, cetak `"Fizz"`.
- Jika angka habis dibagi **5**, cetak `"Buzz"`.
- Jika angka habis dibagi **3 dan 5**, cetak `"FizzBuzz"`.
- Jika angka tidak memenuhi kriteria di atas, cetak angkanya langsung.

### **Contoh**

- **Input:** `n = 5`
- **Output:**
  ```text
  1
  2
  Fizz
  4
  Buzz

### **Deskripsi Soal**
Buatlah sebuah fungsi atau program yang menerima masukan berupa sebuah string `s`, lalu mengembalikan string tersebut dalam urutan yang terbalik.

### **Contoh**

#### **Contoh 1**
- **Input:** `s = "hello"`
- **Output:** `"olleh"`

#### **Contoh 2**
- **Input:** `s = "Coding"`
- **Output:** `"gnidoC"`
