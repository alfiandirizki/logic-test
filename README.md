# Problem Set: FizzBuzz & Reverse String

## 1. FizzBuzz

### **Deskripsi Soal**
Buatlah sebuah fungsi atau program yang menerima sebuah integer `n`. Kembalikan sebuah array/list string dari angka `1` sampai `n` dengan aturan sebagai berikut:
- Jika angka habis dibagi **3**, ganti angka tersebut dengan string `"Fizz"`.
- Jika angka habis dibagi **5**, ganti angka tersebut dengan string `"Buzz"`.
- Jika angka habis dibagi **3 dan 5**, ganti angka tersebut dengan string `"FizzBuzz"`.
- Jika angka tidak memenuhi kriteria di atas, masukkan angka tersebut dalam bentuk string.

### **Contoh**

#### **Contoh 1**
- **Input:** `n = 5`
- **Output:** `["1", "2", "Fizz", "4", "Buzz"]`

#### **Contoh 2**
- **Input:** `n = 15`
- **Output:** `["1", "2", "Fizz", "4", "Buzz", "Fizz", "7", "8", "Fizz", "Buzz", "11", "Fizz", "13", "14", "FizzBuzz"]`

## 2. Reverse String

### **Deskripsi Soal**
Buatlah sebuah fungsi atau program yang menerima masukan berupa sebuah string `s`, lalu mengembalikan string tersebut dalam urutan yang terbalik.

### **Contoh**

#### **Contoh 1**
- **Input:** `s = "hello"`
- **Output:** `"olleh"`

#### **Contoh 2**
- **Input:** `s = "Coding"`
- **Output:** `"gnidoC"`
